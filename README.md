# Phi developer docs

Notes for developers working with Phi, published at https://woodnotfound.github.io/phi-dev-docs/ (GitHub Pages, `main` branch root; every page is `noindex`).

To change a page, edit `src/<name>.md` (diagrams in `src/img/<name>/`, listed in `build.mjs`), run `npm install && npm run build`, then commit and push.
